# Installation

## Requirements
- Windows
- VS Code 1.90+
- Node.js 20+
- Local access to the workstation

## Setup
1. Clone the repository.
2. Open the project in VS Code.
3. Run `npm test` to confirm the repo guardrails.
4. Use the VS Code extension host to activate the bridge.

## Security notes
The token is stored in VS Code SecretStorage and is never written to the repo or settings file.
